# This program
This is an implementation for 3 different local search algorithms, this includes
Hill-Climbing (Steepese Ascent only), Simulated Annealing, and Genetic Algorithm.
# How to run
 - Make sure you have at least [python 3](https://www.python.org/downloads/) installed
 - Make sure you have [uv](https://uvicorn.dev/installation/) installed
 - from the root directory run
 ```bash
 uv run streamlit run src/main.py
 ```
 - open the localhost provided in your browser
 - input your packages and truck config manually or use a json
 - press the run button at bottom of the sidebar
 - results will always be saved at the [output](./output/) directory
